Eine kleine Analyse-App, die vergangene *Jugend forscht*-Projekte auswertet und Trends über die Jahre und Fachgebiete hinweg visualisiert.

## ✨ Features

- 🔎 Automatischer Scraper für Projektdaten
- 📈 Interaktive Graphen & Auswertungen
- 🧪 Aufschlüsselung nach Fachgebieten (Physik, Technik, Geo/Raum …)
- 🗓️ Daten der letzten Jahre (2021–2025)

## 🛠️ Tech-Stack

`Python` · `Streamlit` · `pandas` · `matplotlib`

## 🚀 Lokal starten

```bash
pip install -r requirements.txt
streamlit run main.py
```
